## 2. Report service in core

- [ ] 2.1 Define the `ReportService` interface and the `Report` data types from the design, and add `createReportService` with date handling: `from` defaults to today from the `Clock`, `to` defaults to `from`, both are checked with `isIsoDate`, `to` before `from` is an error, and `kind` is `range` when two dates are given; verify unit tests with the clock mock for no date, one date, two equal dates, an invalid date and a reversed range
- [ ] 2.2 Calculate each entry of a valid day: reference entries through `catalog.resolve` and `nutrition.amountOf` with the line's unit or the default unit, inline entries mapped to every catalog id with absent values as 0; include `line`, the reference fields (`slug`, `version`, `item`, `name`, `amount`, resolved `unit`) or `description`; verify with the in-memory file system that a day with a food, a recipe serving and an inline entry gives the spec's totals (136.255 + 800 = 936.255 kcal), and that a nested recipe entry contributes the expected fraction
- [ ] 2.3 Build meal and day totals and the meal order: configured meals in config order, then unknown meals in first-seen order, merged duplicate sections, meals without entries omitted, each with `configured`; verify unit tests for sections out of order, duplicate sections, an empty section and an unknown meal
- [ ] 2.4 Build a range: one `ReportDay` per date with `logged`, then `loggedDays`, the range `totals`, `averageDays` (logged days other than today) and `average` (undefined when none remain); include entries only for a day report or when `entries` is set; verify unit tests for days not logged, today in the range, only today logged, and entries omitted and included
- [ ] 2.5 Make reports strict: collect validation errors from every day and calculation errors located at the day file and entry line (followed by any problems they carry), and after all dates throw one `NomnomError` with every problem and a message saying which days have errors; pass warnings through in `warnings`; verify unit tests for invalid lines on two days of a range, a recipe cycle found only while calculating, and an unknown meal that only warns
- [ ] 2.6 Wire `createReportService` into `createServices` with the existing `nutrition` instance, add `report` to `Services`, and export the interface and report types from `src/index.ts`; verify `services.test.ts` covers the new service and `bun run typecheck` passes
